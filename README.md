Age Calculator Using Python

Project Description

A simple Python application that calculates a person's exact age based on their date of birth.

Features

- Accepts user's name and date of birth.
- Calculates age in years, months and days.
- Prevents future birth dates.
- Handles invalid date inputs.
- Supports leap-year dates.

Technologies Used

- Python
- Spyder IDE
- datetime module
- calendar module

How to Run

1. Install Python.
2. Open age_calculator.py in Spyder.
3. Press F5 to run the program.
4. Enter your name and date of birth in YYYY-MM-DD format.

Testing

Tested with normal dates, future dates, invalid text, invalid calendar dates and leap-year birthdays.
